# Browser speech validation — 2026-11-10

## Shipped scope

- Existing Supertonic F1–F5/M1–M5 profiles and its 31 languages are retained.
- Persian (fa) and Mandarin Chinese (zh) use OmniVoice with a reference generated from the selected existing profile. All ten references are bundled as small audio-token JSON files. There is no runtime voice encoder download.
- Hebrew was tested but **not enabled** for reference-based speech because the validation found substantial pronunciation errors. Available operating-system voices remain an alternative, with different timbre.
- The default F1 tour has prerecorded introduction + 19 steps in Dutch, English, Persian and Mandarin. Other profiles/languages retain on-device generation and the existing tour cache. No other profile is silently replaced by F1.
- Model inference runs in the learner's browser. No account, paid TTS API, or school server is needed. Static recordings still use the hosting provider's ordinary bandwidth allowance.

## Runtime limits

New fa/zh answers require WebGPU with shader-f16 and approximately 1.3 GB of model files on first use. Files persist in browser storage when available; storage eviction can require another download. Inference is not instantaneous and depends on hardware. The recorded tour needs only its small MP3 files, not this model. Existing Supertonic warmup remains independent.

The engine is deliberately configured with `lowMemory:true` to reject unsupported GPUs instead of falling back to a larger 2+ GB CPU download. Stop/cancel preserves an initialized worker. A failed natural voice reports an error instead of silently changing voice identity.

## Actual validation

Browser: local in-app Chromium browser on Apple Silicon, 16 GB RAM. WebGPU and shader-f16 verified. Same F1 English reference used for fa, zh, he and nl. The reference itself is generated by the existing Supertonic engine, not a person's recording.

At 16 diffusion steps, short sample generation took 3.4–5.2 seconds after loading. The final integration uses 40 steps for quality; this is slower (the Dutch control sample took 7.8 seconds). Do not present the faster experimental timings as final-product latency.

Independent CPU Whisper small and medium transcriptions checked the audio. Medium transcriptions of the 40-step samples:

| Language | Expected | Recognized |
| --- | --- | --- |
| Persian | سلام. من مربی زبان شما هستم. امروز با هم هلندی یاد می‌گیریم. | سلام من مربی زبان شما هستم. امروز با هم هولندی یاد میگیریم. |
| Chinese | 你好，我是你的语言教练。今天我们一起学习荷兰语。 | 你好,我是你的语言教练今天我们一起学习荷兰语 |
| Hebrew | שלום. אני מאמנת השפה שלך. היום נלמד יחד הולנדית. | שלום, אני מעמנת השפעה שלה, היום נמד, יא-הד-הולנדית |
| Dutch control | Hallo, ik ben je taalcoach. Vandaag leren we samen Nederlands. | Hallo, ik ben je taalcoach. Vandaag leren we samen Nederlands. |

Hebrew was additionally tested with niqqud, a native-accent instruction and simpler wording; results still contained errors. Those experiments were not promoted to supported speech.

ASR is an imperfect proxy for intelligibility, **not** a native-speaker pronunciation review or proof of identical voice identity. Same-reference voice transfer may retain an accent or change timbre. Only F1 received the cross-language speech recognition comparison; the other nine existing profiles were encoded but not each pronunciation-rated in fa/zh.

Tour recordings receive an automated audio/ASR pass, with findings in `tour-audio-validation.json`. A teacher/native speaker should review before use for pronunciation assessment.
